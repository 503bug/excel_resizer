# Excel/WPS 批量调整列宽行高

> 一键批量修改文件夹内所有 `.xlsx` 文件的列宽和行高，**完整保留嵌入图片、图表、公式、样式等所有内容**。

![Python](https://img.shields.io/badge/Python-3.8%2B-blue)

---

## ✨ 特性

- 🖱️ **图形界面**，选择文件夹即可批量处理
- 🧩 **三种处理引擎**，按需选择
- 🖼️ **零内容损失**：XML 直改模式 100% 保留 WPS 嵌入图片、图表、批注、条件格式
- 📁 **支持递归**：可包含子文件夹
- 🎯 **精确控制**：自由指定列范围（如 `A:Z`）与行范围（如 `1:100`）
- ⏹️ **可随时停止**：处理过程中点击「停止」，当前文件完成后即中断
- 📊 **实时进度条 + 详细日志**

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

> 建议使用虚拟环境：
>
> ```bash
> python -m venv venv
> # Windows
> venv\Scripts\activate
> # Linux / macOS
> source venv/bin/activate
> pip install -r requirements.txt
> ```

### 2. 运行程序

```bash
python excel_resizer.py
```

### 3. 使用步骤

1. 点击 **浏览...** 选择包含 `.xlsx` 文件的文件夹
2. 填写参数：
   - **列宽(字符)**：如 `10`
   - **行高(磅)**：如 `15`
   - **列范围**：如 `A:Z`（留空 = 不修改列宽）
   - **行范围**：如 `1:100`（留空 = 修改所有已有行）
3. 选择处理引擎（默认 XML 直改）
4. 按需勾选 **包含子文件夹**
5. 点击 **开始处理**，等待完成

## 🧩 三种处理引擎对比

| 引擎 | 依赖 | 是否需要 Office | 内容保留 | 推荐场景 |
|------|------|----------------|----------|----------|
| **XML 直改** ⭐ | `lxml` | ❌ 不需要 | ✅ 100% 保留 | 绝大多数场景 |
| **COM** | `pywin32` + WPS/Excel | ✅ 需要 | ✅ 完整保留 | 需要复杂格式重算时 |
| **openpyxl** | `openpyxl` | ❌ 不需要 | ⚠️ 可能丢失图片/图表 | 不推荐，仅应急 |

### 为什么推荐 XML 直改？

`.xlsx` 本质是 ZIP 包，内部由 XML 描述。XML 直改只重写 `xl/worksheets/sheetN.xml` 中与列宽行高相关的节点，**其他所有文件（图片、图表、VBA、批注等）原封不动复制**，因此：

- 无需安装 Office/WPS
- 速度快（毫秒级/文件）
- 跨平台（Windows / Linux / macOS）
- 无内容丢失风险

## ⚠️ 注意事项

1. **请先备份重要文件**，本工具会直接覆盖原文件。
2. 处理时请勿在 Excel/WPS 中打开目标文件。
3. 跳过 `~$` 开头的临时文件（Office 锁文件）。
4. XML 直改模式下，修改后的文件首次打开时，Excel 可能重建部分索引，属正常现象。

## 🐛 常见问题

### Q1: 提示 `lxml 未安装`？

```
"你的python路径" -m pip install lxml
```

请确保 GUI 顶部 **解释器** 显示的 Python 路径与安装依赖使用的路径一致。

### Q2: COM 引擎报错找不到 WPS/Excel？

- 确认已安装 WPS 或 Microsoft Excel
- 确认已安装 `pywin32`：`pip install pywin32`
- 推荐直接切换到 **XML 直改** 引擎

### Q3: 处理完成后图片丢了？

请确认使用的是 **XML 直改** 或 **COM** 引擎。`openpyxl` 引擎在保存时会重新生成文件，可能丢失部分嵌入资源。

### Q4: 支持 `.xls` 或 `.xlsm` 吗？

当前仅支持 `.xlsx`。`.xlsm` 可尝试修改扩展名后使用 XML 直改模式（VBA 会被保留），但未做完整测试。
